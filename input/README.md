Download the training data from the official [IEEE-CIS Fraud Detection competition data page](https://www.kaggle.com/competitions/ieee-fraud-detection/data). Place these two downloaded files locally:

```text
input/ieee/train_transaction.csv
input/ieee/train_identity.csv
```

Download the S-FFSD dataset from the `data` directory of the official [AI4Risk/antifraud](https://github.com/AI4Risk/antifraud) repository. Extract `S-FFSD.zip` and place the resulting file locally as:

```
input/S-FFSD.csv
```

The downloaded S-FFSD and IEEE-CIS data files are excluded from version control.
