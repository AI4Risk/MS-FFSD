# MS-FFSD Dataset

This directory contains the released **MS-FFSD** dataset generated by this repository.

The dataset is provided as:

```text
MS-FFSD.zip
```

The archive contains five CSV files:

```text
transaction.csv
user.csv
merchant.csv
user_description.csv
merchant_description.csv
```

For dataset construction details, schema descriptions, and reproduction instructions, please refer to the [root README](../README.md).
